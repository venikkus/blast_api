# Запуск BLAST-поиска по WGS

Инструмент запускается из терминала: передайте FASTA-файл и выбранную группу организмов аргументами команды. Код в Python-скрипте редактировать не нужно.

## Установка

Из корня проекта выполните:

```bash
cd /Users/venikkus/IB/python/blast_api
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[test]'
```

При следующих запусках активируйте окружение командой `source .venv/bin/activate`.

## Запуск для Insects

```bash
blast-wgs --query data/queries/KR704917.1.fasta \
  --organism Insects --program blastn \
  --batch-size 250 --output-dir results/insects
```

Если пакет ещё не установлен, используйте тот же интерфейс через Python:

```bash
python search_wgs.py --query data/queries/KR704917.1.fasta \
  --organism Insects --program blastn \
  --batch-size 250 --output-dir results/insects
```

`--organism` принимает имя таксона; параметр можно повторить. Для явного выбора NCBI TaxID используйте `--taxid`, а для исключения ветви таксономии — `--exclude-taxid`. Уточнить параметры можно командой `blast-wgs --help`.

Выберите программу по типу запроса:

| Запрос | Программа |
| --- | --- |
| ДНК против геномной ДНК | `blastn` |
| Белок против переводимых участков генома | `tblastn` |

## Пакетная обработка и продолжение

По умолчанию WGS-проекты разбиваются на группы по 250. Для 10 985 проектов Insects получится примерно 44 задания BLAST, отправляемых последовательно. В одном запуске допускается до 50 пакетов; настройте размер через `--batch-size` и предел через `--max-batches`.

В каталоге результата появятся `manifest.json`, отдельный `batch_NNNN.rid.json` для RID и `batch_NNNN.tsv` для результата каждого завершённого задания. `results.tsv` пересобирается после каждого пакета. Если процесс прервётся, повторите ту же команду с теми же параметрами и каталогом: незавершённый RID будет продолжен, завершённые пакеты пропускаются. Каталог запуска привязан к последовательности и параметрам; для нового поиска выберите другой `--output-dir`.

Каждый пакет — отдельный поиск со своей статистической базой, поэтому E-values из разных пакетов нельзя напрямую ранжировать или сравнивать. Пакетирование позволяет ограничить размер одного задания и возобновить работу; оно не гарантирует более быстрое завершение всего поиска.

## Уже отправленный RID

Если до перехода на CLI был отправлен RID (например, `BWSX16VE014` для поиска сразу по всем 10 985 проектам), это задание остаётся отдельным. Новый пакетный запуск не может превратить его в серию пакетов. Не отправляйте тот же запрос повторно без необходимости; результат старого RID нужно получить отдельно через прежнюю сессию/клиент.

## Интервалы NCBI

Клиент делает паузу перед отправкой поисков, а состояние одного RID проверяет не чаще раза в минуту. Не запускайте несколько массовых поисков параллельно. Для больших очередей и рекомендуемых часов использования ознакомьтесь с [правилами NCBI BLAST API](https://blast.ncbi.nlm.nih.gov/doc/blast-help/developerinfo.html).
